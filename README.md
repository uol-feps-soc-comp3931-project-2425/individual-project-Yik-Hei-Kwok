# Patch Based Synthesis Block Building Application
This project involves a building application where users are able to define textures of building blocks, and place building blocks onto the terrain.
Textures are generated for blocks using a patch synthesis algorithm influenced by Lin Liang et al. (2001) research https://people.csail.mit.edu/celiu/pdfs/TOG.pdf


## How To Run the Program
Within this repositry, there contains a folder named "Final_Build". Run the executive file in that folder to run the application

## Controls
W A S D: Player Movement across the plane

Space (single tap): Jump / Fly upwards

Space (double tap): Switch between Jump and Fly modes

M: Create New Block

Left Click: Destroy Blocks

Right Click: Place Blocks

Keys 1-9: Change Inventory



## Things to Note when running the Application
### File Input Conditions
When choosing textures for a block texture, a file browser will appear. THis system doesn't validate file types, so make sure images of either JPG or PNG file formats are chosen.

Also make sure images of at least 50x50 pixels are chosen.

A folder named "Reference Images" contain images I have used for the project's evaluation, feel free to use these images as input if needed.

### Block Limit
Since this application is just a prototype, it only supports 9 blocks. Please do not create more than 9 blocks in a single use
